Use a local Tau backend

Load the matching tau.esm.mjs and tau.esm.wasm from a release-wasm-nothreads build obtained from IDNI. Files stay on this device. The selected JavaScript executes in the chat worker.

Experimental adapter. Tau computes the 64 possible gate results, which are memoized across the graph. JavaScript schedules nodes and sums votes. This does not invoke the native Mealy-table compiler.

How the conversation works

The topic network learns two-input Boolean tables. Frozen table outputs vote for an algorithm or formal-methods topic. A separate 3,072-table network scores lexical relevance for retrieved questions.

Topic explanations are authored cards. Broader replies are displayed from attributed OpenAssistant and Dolly subsets. The agent does not synthesize fresh prose or run a remote language model.

Conversation context retains the current algorithm topic or a source awaiting confirmation. Clear resets it. Chat messages remain in memory on this page.
